# Portfolio Mohammed Hebbada

Portfolio personnel moderne — AI & Data Engineering.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Démarrage

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
